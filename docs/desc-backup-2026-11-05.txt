Halimi is an agent that shows not only what it knows but what it did - with a receipt for every step. Each answer carries an immutable INVOICE: what it understood, which tool it used, how long it took, what it refused and why. Invoices are chained by hashes, and a verification endpoint shows where the chain breaks. Three layers: understanding (model), action (SQL over Kosovo public procurement OCDS, auditing, policy), receipt. Scenarios: 8,736 contracts / EUR 728.5M queried with sources; 26,561 audit entries; refusal of file extraction with a stated reason.
