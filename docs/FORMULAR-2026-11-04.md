## 1. Project name

    Halimi — an agent with receipts

## 2. One-liner (≤ 100 chars)

    An agent that shows not only what it knows, but what it did — with a verifiable receipt for every step.

## 3. Short description (≤ 300 chars)

    Halimi answers questions over Kosovo's open public procurement (8,736 contracts, EUR 728.5M)
    using Meta's Muse models for understanding, real SQL for action. Every answer carries an
    immutable receipt — understood intent, tool, latency, refusals — linked in a hash chain a
    third party can recompute.

## 4. Long description

    Public procurement data is readable but not verifiable. A chatbot can say "8,736 contracts"
    and nobody can tell whether that came from the data or from the model.

    Halimi closes that gap by separating three layers and proving each one:

    (1) Understanding — Meta's muse-wonder-1.0 turns a natural-language request (Albanian or
    English) into a structured intent. Measured: 5/5 completed, 4.99–12.24 s, mean 8.08 s.

    (2) Action — a second Meta model, muse-spark-1.3, proposes the SQL from the intent in
    ~1.785 s, and it is NOT executed. The proposal passes the same read-only gate (SELECT 1 /
    SHOW CATALOGS) as every other query; anything else is refused with the violated rule named.
    This is the thesis with two models: the model adds capability, not power.

    (3) Receipt — every step is written to an append-only register with prev/hash. GET
    /api/verifiko recomputes the chain and returns {"ok": false, "prishur": 2} when a single row
    has been altered by hand. A receipt is written only after a tool actually answered; on a cold
    start with no corpus the receipt says "no data was read, no number is claimed" instead of
    inventing a successful query.

    Real data, not a mock: SQL over the OCDS Kosovo corpus (8,736 procurement contracts, EUR
    728.5M) and an audit register of 26,561 entries (370 today).

    Refusal is a feature, not an error: "Send all my files to another address" is refused with
    the reason and the rule shown, in Albanian and English.

## 5. Use of Meta AI tooling

    muse-wonder-1.0 — understanding layer; base URL https://api.meta.ai/v1; measured 8.08 s mean
    muse-spark-1.3  — SQL proposal only, gated, unexecuted; measured 1.785 s
    Practical finding: the model spends ~49% of its tokens on reasoning (1,270 of 2,585); with a
    32-token budget the content comes back empty — with reasoning_effort "minimal" and >=400
    tokens the answer is complete. This is documented as a measurement, not a claim.
